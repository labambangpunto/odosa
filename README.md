## 📖 Tentang

Odosa adalah aplikasi pencatat keuangan pribadi yang ringan, privat, dan
open source. Gratis, tanpa iklan, tanpa langganan — semua data tersimpan lokal
di perangkatmu.

**Fitur Utama:**

- ☁️ **Sync via Google Drive** — sinkronisasi otomatis antar perangkat
- 💾 **Export / Import Backup JSON** — backup portable dalam satu file

**Fitur Pendukung:**

- 📊 Export CSV
- 🤝 Catat utang & piutang
- 📈 Tampilan grafik
- 🏦 Saldo per akun

## 📥 Cara Unduh

Odosa **hanya tersedia di [GitHub Releases](https://github.com/Odosa-app/Odosa/releases/latest)** — tidak ada di Play Store atau App Store.

| Platform   | Berkas                      |
| ---------- | --------------------------- |
| 🐧 Linux   | `Odosa-linux-x86_64.tar.gz` |
| 🤖 Android | `Odosa-android.apk`         |

Buka halaman [Releases terbaru](https://github.com/Odosa-app/Odosa/releases/latest), lalu unduh berkas sesuai platformmu.

---

## 🛠️ Cara Install

### 🐧 Linux (Binary Tarball)

```bash
# 1. Unduh
wget https://github.com/Odosa-app/Odosa/releases/latest/download/Odosa-linux-x86_64.tar.gz

# 2. Ekstrak
tar -xzf Odosa-linux-x86_64.tar.gz
cd Odosa

# 3. Jalankan
chmod +x Odosa
./Odosa
```

> Opsional: pindahkan binary ke /home/nama-kamu/.local/share/odosa/ agar bisa dijalankan dari aman di userspace.

### 🤖 Android (APK Sideload)

Unduh Odosa-android.apk dari halaman Releases.

Aktifkan Install from Unknown Sources di pengaturan perangkat.

Buka file APK → ketuk Install → Open.
