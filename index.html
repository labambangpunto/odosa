Fitur

Dua fitur utama, empat pendukung

FinTrack dibangun di atas dua pilar: sinkronisasi cloud lewat Google Drive dan backup JSON yang bisa dibawa ke mana saja. Sisanya melengkapi pencatatan harianmu.

Utama

Sync via Google Drive

Sinkronisasi otomatis ke akun Google Drive-mu. Catat di ponsel saat di jalan, buka di laptop saat sampai rumah — saldo, transaksi, dan utang-piutang selalu dalam kondisi yang sama.

Auto sync Multi-device Aman
Utama

Export / Import Backup JSON

Simpan seluruh data dalam satu file JSON yang rapi. Pindah perangkat, ganti aplikasi, atau simpan cadangan pribadi — tinggal ekspor, lalu impor kembali kapan pun dibutuhkan.

Portable Restore cepat Human-readable

Export CSV

Ekspor transaksi ke CSV untuk diolah di Excel, Google Sheets, atau tools analisis favoritmu.

Catat Utang & Piutang

Kelola utang dan piutang dengan jelas — siapa berhutang, berapa, dan kapan jatuh temponya.

Tampilan Grafik

Grafik batang, donut, dan tren bulanan yang langsung memberi gambaran kondisi keuanganmu.

Saldo per Akun

Pisahkan saldo tiap akun — tunai, rekening bank, e-wallet — agar tahu persis di mana uangmu berada.

Unduh FinTrack sekarang

FinTrack hanya tersedia untuk Linux dan Android. Tidak ada di Play Store, App Store, maupun Microsoft Store — semua versi rilis dipublikasikan langsung di halaman GitHub Releases agar selalu transparan dan bebas dari bloatware.

Linux Tarball Only

Tersedia dalam bentuk binary tarball yang siap diekstrak dan dijalankan. Tidak ada paket .deb, .rpm, maupun .AppImage.

fintrack-linux-x86_64.tar.gz x86_64 Portable

Android

Unduh berkas .apk langsung dari GitHub Releases, lalu pasang secara manual (sideload). Pastikan opsi "Install from unknown sources" aktif di pengaturan perangkatmu.
